### Which project(s) to build

Build **Project 1 first, always** — it's the foundation every IAM role expects to see. Then pick **one** of Projects 2-4 based on your target role. Two deep, well-documented projects beat four shallow ones — depth is what survives follow-up questions in an interview. This repo scaffolds all four so you can choose; you don't need to complete all of them to have a strong portfolio.
