# Certification Roadmap

A planning reference — not certificates yet. Once you earn one, add it to the table in the root [`README.md`](../README.md) and drop the certificate image in a subfolder here.

| Certification | Level | Focus |
|---|---|---|
| Microsoft SC-900 (Security, Compliance & Identity Fundamentals) | Entry | Broad conceptual foundation — great starting point |
| Microsoft SC-300 (Identity and Access Administrator) | Associate | The core IAM administrator credential |
| Microsoft AZ-500 (Azure Security Engineer Associate) | Associate | Broader Azure security including IAM, networking, and data protection |
| CompTIA Security+ | Entry | Vendor-neutral security fundamentals, often a prerequisite in job postings |
| (ISC)² CISSP | Advanced | Broad security management credential; useful once you have 4-5 years' experience |
| CyberArk Defender / Sentry | Specialist | Vendor-specific PAM certification, valuable if targeting PAM engineer roles specifically |
| SailPoint Certified IdentityNow Associate/Engineer | Specialist | Entry point into SailPoint's official certification track — governance/IGA-focused roles |
| SailPoint Certified IdentityIQ Architect | Advanced | Deep, implementation-level SailPoint credential — strong for senior IGA engineer roles |
| Okta Certified Professional | Entry | Okta's own entry-level credential — basic admin tasks, groups, apps, provisioning |
| Okta Certified Administrator | Associate | Deeper Okta admin: policies, MFA, provisioning integrations, troubleshooting |
| Okta Certified Consultant | Advanced | Complex, multi-org Okta architecture and implementation — strong for senior/consulting roles |
| Microsoft SC-200 (Security Operations Analyst) | Associate | Triage, incident response, Defender tools |
| CompTIA CySA+ (Cybersecurity Analyst) | Associate | Vendor-neutral SecOps/triage credential, pairs well with SC-200 |
| HashiCorp Terraform Associate | Associate | Validates Infrastructure-as-Code skills — increasingly listed on engineer-level (not admin-level) IAM postings |

## Suggested order for a complete beginner

1. **SC-900** — validate the fundamentals first.
2. **SC-300** — once you've done the hands-on Entra ID labs (Project 01 territory).
3. **AZ-500** or a PAM-vendor cert, depending on which specialization you pursue.
4. If a target employer runs Okta alongside (or instead of) Microsoft: **Okta Certified Professional** — inexpensive, fast to earn, and directly signals dual-platform fluency.
5. If targeting PAM-engineer or IGA-engineer titles specifically: a **SailPoint** or **CyberArk** associate-level cert once fundamentals are solid.
6. If targeting an engineer (not administrator) title: **Terraform Associate** paired with an Infrastructure-as-Code project is a genuine differentiator — rare among IAM candidates.

> The strongest entry-level resume combination right now: **SC-900 + SC-300 + Okta Certified Professional** — it proves fundamentals, proves hands-on Microsoft depth, and proves you aren't a single-vendor specialist, for a relatively small time and cost investment.
